CONSTRUIRE LE JEU DEPUIS GITHUB

Vous pouvez aussi compiler Boufbowl Fan depuis les sources du projet sur GitHub. Voici les étapes sur une machine Linux.

  1. Installer les outils. Git, Bun, Python 3 et Java 17 ou plus récent sont nécessaires pour compiler le jeu.
  2. Récupérer les sources. 
    git clone https://github.com/theonaciri/boufbowl_swf.git
cd boufbowl_swf
  3. Compiler le client du jeu. FFDec est téléchargé automatiquement si nécessaire. 
    bun run build
    Le client compilé est créé dans bin/boufbowl-client-1.9.6.swf.
  4. Créer une application pour la plateforme de votre choix. 
    # Windows
bun run build:players --platform windows
# Linux
bun run build:players --platform linux
# Android
bun run build:players --platform android
    Pour Windows et Linux, ajoutez le lecteur Flash dans bin/flashplayer_32_sa.exe et installez FFmpeg ; Windows nécessite aussi NSIS. Pour Android, installez FFmpeg, l’AIR SDK, l’Android SDK et un JDK 17 ou plus récent. Les SDK installés sont recherchés automatiquement.

Retrouvez les prérequis détaillés et les emplacements des fichiers générés dans le guide de compilation.

On cherche aussi des bénévoles pour rendre le jeu fiable sur le Web : spécialiste de Ruffle, de Flash/AS3, du rendu ou des performances navigateur, venez nous aider à trouver une solution. Les ateliers de restauration de cette page sont en HTML et JavaScript, sans émulateur.

Ce n’est pas encore le grand lancement. C’est une reconstruction jouable, en évolution, sur Web, Android et Desktop. Une belle occasion d’entrer dans l’équipe avant le coup d’envoi officiel.
