ON A RETROUVÉ LE JEU.
PAS TOUTES SES CHAUSSETTES.

RESTAURATION
EN COURS ↗

Le client Flash d’origine a été sauvé des vestiaires du temps. Dans son sac : à peu près la moitié des ressources. Depuis, on recoud les maillots, on remet le serveur sur pieds et on tente de rendre au Boufbowl sa bonne vieille mauvaise humeur.

Ce n’est pas encore le grand lancement. C’est une reconstruction jouable, en évolution, sur Web, Android et Desktop. Une belle occasion d’entrer dans l’équipe avant le coup d’envoi officiel.

SOUS LE MAILLOT, COMMENT ÇA TOURNE ? +

Le client originel, des correctifs ActionScript 3, un serveur actuellement écrit en Python, une base SQLite et des ressources supplémentaires. Le serveur pourra évoluer ; la priorité reste de retrouver le jeu. Le dépôt GitHub est encore privé. Demandez l’accès pour contribuer ; l’ouverture du code est prévue après le nettoyage du projet et son lancement.

04 / CHOISISSEZ VOTRE TERRAIN

LES MÊMES BAFFES.
TROIS FAÇONS DE LES PRENDRE.

Pour jouer dans les meilleures conditions, privilégiez le client Desktop ou l’application Android. Le navigateur sert surtout aux plus téméraires.

LE BON PLAN : DESKTOP OU ANDROID.

Ces deux clients sont les versions à privilégier pour jouer. Sur le Web, le client Flash passe par l’émulateur Ruffle : cette version est lente, présente des bugs et reste instable.

BUILD DISPONIBLE

DESKTOP

Le client Desktop est recommandé pour jouer. Il se connecte au serveur du jeu : aucun serveur local ni Python à installer.

LINUX · TÉLÉCHARGER ↗Linux x86-64 · Wine requis · sans Python BUILD DISPONIBLE WINDOWS · TÉLÉCHARGER ↗Windows · sans Wine ni Python
BUILD DISPONIBLE

ANDROID

L’application Android fait partie des façons recommandées de jouer. La tactique au bout des doigts, les crampons en moins. Tous les assets disponibles sont inclus dans l’APK ; les parties utilisent le serveur distant.

TÉLÉCHARGER L’APK ↗APK · Android 6+ · ARM64
EXPÉRIMENTAL · RUFFLE

WEB

Le client Flash tourne ici avec Ruffle. C’est lent, parfois bugué et instable : pour un vrai match, choisissez plutôt Desktop ou Android.

ESSAYER LA VERSION WEB ↗Version expérimentale · lente, buguée et instable

On cherche aussi des bénévoles pour rendre le jeu fiable sur le Web : spécialiste de Ruffle, de Flash/AS3, du rendu ou des performances navigateur, venez nous aider à trouver une solution. Les ateliers de restauration de cette page sont en HTML et JavaScript, sans émulateur.
