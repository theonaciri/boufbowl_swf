Use an existing administrator session

Use an existing account with the admin role. On the server, assign the role by account username with python3 -m backend.manage role --account "Username" admin. Account usernames can differ from game nicknames. If the server uses a custom database, put --database /path/to/backend.sqlite before role.

Users count distinct profiles; profiles and accounts do not necessarily identify distinct people.
